# Accessibility and UX audit — RC-1 (goal 10)

Lead: S1 (principal product designer). Standard: WCAG 2.2 AA. Run: 2026-09-27 on the native e2e
stack (Chromium from `/opt/pw-browsers`), three consecutive e2e runs (plan 10 §6).

## 1. Automated WCAG 2.2 AA (axe) on every route

`apps/web/e2e/a11y-routes.spec.ts` scans every page of the app router with axe tags
`wcag2a, wcag2aa, wcag21a, wcag21aa, wcag22aa`, as the role(s) that can open it, and fails on any
serious or critical violation and on any colour-contrast violation.

| Route group | Routes | Theme | Result |
|---|---|---|---|
| Public | `/login`, `/signup`, `/reliability`, `/offline` | novice-light | 0 serious/critical, 0 contrast |
| Novice | `/onboarding`, `/home`, `/practice`, `/learn`, `/learn/[lesson]`, `/learn/check`, `/auto-invest`, `/portfolio`, `/settings`, `/appropriateness`, `/forbidden` (a Pro-only route opened by a novice) | novice-light | 0 serious/critical, 0 contrast |
| Pro | `/terminal`, `/robots`, `/robots/builder`, `/simulator`, `/radar`, `/audit`, `/portfolio`, `/settings` | pro-dark | 0 serious/critical, 0 contrast |
| Second / third line | `/risk` (risk officer), `/internal-audit` (auditor) | pro-dark | 0 serious/critical, 0 contrast |

All 23 `page.tsx` routes are covered. The design system is also scanned story by story in Chromium
in both themes (`pnpm --filter @kora/ui test:storybook-axe`, CI step "Storybook axe") and the token
contrast check runs in CI (`pnpm contrast`). Module specs keep their deeper per-screen scans
(terminal, novice, robots, simulator, governance).

## 2. Keyboard-only walkthrough

`a11y-routes.spec.ts` "keyboard-only walkthrough" and `terminal-a11y-perf.spec.ts`:

- the first Tab stop is "Skip to content" and Enter moves to `<main id="main">`;
- every focusable control in the top bar shows a visible focus indicator;
- the kill switch opens with a 1.5 s Space hold from the keyboard; Escape closes it and focus returns
  to the button (goal 10 fix: dialogs return focus to their opener);
- the ⌘K / Ctrl+K palette opens from the keyboard, focus moves into the dialog, Escape closes it;
- ticket to fill by keyboard only: B, order type, quantity, Ctrl+Enter, hold-to-confirm with Space.

## 4. Colour convention

`a11y-routes.spec.ts` "colour convention": buy/up = blue `#4DA3FF` and sell/down = orange `#FF9F40`
by default; the Settings switch changes the tokens; ▲/▼ glyphs always accompany direction in the
watchlist, ticket and blotter, so colour is never the only cue. Dark ink on buy/sell fills (OQ-D2,
Sponsor decision) keeps text contrast above 7:1.
