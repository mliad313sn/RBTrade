## Placeholder register check (goal 09)

Every regulatory or policy placeholder in the product names an open question above, and every open
question has an owner. A unit test (`apps/api/src/governance/governance.unit.test.ts`) fails when the
code references an `OQ-*` id that is not in this table or a row has no owner. Values reach the product
only through the disclosures registry (four-eyes publication) or reviewed configuration; nothing here is
legal advice.
